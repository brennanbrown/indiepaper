# Contributing

Thanks for contributing! Please be respectful and constructive.

## Reporting Issues

Check existing issues first. For bugs, include:
- Steps to reproduce
- Expected vs actual behavior
- Hugo version and environment

## Pull Requests

1. Fork and create a branch
2. Make focused changes following existing style
3. Test thoroughly
4. Commit with clear messages
5. Submit PR

## Development

```bash
git clone https://github.com/brennanbrown/indiepaper.git
cd indiepaper/exampleSite
hugo server -D
```

## Standards

- Follow existing code style
- Maintain WCAG 2.1 AA compliance
- Keep IndieWeb microformats2 support
- Test on multiple devices
