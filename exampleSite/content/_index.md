Welcome to Indiepaper, a brutalist Hugo theme that prioritizes smolweb principles, accessibility, and IndieWeb protocols.

## Features

- **Semantic HTML5**: Proper use of header, main, article, section, and other semantic elements
- **IndieWeb Native**: Full microformats2 support with h-card and h-entry
- **Accessibility First**: WCAG 2.1 AA compliant with skip links and proper ARIA labels
- **Monochrome Design**: Pure black and white aesthetic with no embedded fonts
- **Performance Optimized**: Single CSS file, minimal JavaScript, fast loading

## Getting Started

This is the example site for the Indiepaper theme. Browse around to see the different page types and layouts in action.
