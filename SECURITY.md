# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.x     | ✓         |

## Reporting Vulnerabilities

**Do not** open public issues for security vulnerabilities.

Email: brennan@berryhouse.ca

Include:
- Vulnerability description
- Steps to reproduce
- Potential impact

Response time: Acknowledgment within 48 hours, detailed response within 7 days.
